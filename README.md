# インストール法
- 一回インストールするとアンインストールするまでフォルダを動かせられないので、あらかじめフォルダをインストールしたいところに動かす。
- コマンドプロンプトを、管理者権限で実行。
- `cd （インストール場所）\PhunIME1.0.0\cpp\x64\Debug`と実行。
- `regsvr32 SampleIME.dll`と実行。
- Windows設定での言語に簡体中国語を追加。

# アンインストール法
- `cd （インストール場所）\PhunIME1.0.0\cpp\x64\Debug`と実行。
- `regsvr32 /u SampleIME.dll`と実行。
- パソコンを再起動。
- ファイルを削除。

# 使い方
- Windows+Shiftで「Chinese Simplified Sample IME」みたいなやつを選択。
- Shiftでローマ字と雰字を切り替える。
- 辞書登録は一応txtファイルを直接いじることでできるが、壊れやすいので自己責任で。なおいじるためにはアンインストールの削除以外の段階を踏む必要があり、いじった後は再インストールする必要がある。
